📝 To-Do List (Evolução do Projeto)

Este projeto começou como uma aplicação simples de lista de tarefas em JavaScript e evoluiu para uma versão completa com API e banco de dados.

A ideia foi praticar na prática a evolução de um projeto frontend para uma aplicação fullstack.

---

🚀 Versões do Projeto

🔹 Frontend Simples
Aplicação inicial feita com:
- HTML
- CSS
- JavaScript

Funcionalidades:
- Adicionar tarefas
- Listar tarefas
- Remover tarefas

📁 Pasta: `/frontend-simples`

---

🔹 Fullstack (API + Banco)
Evolução do projeto com integração completa:

- Node.js
- Express
- Prisma
- PostgreSQL

Funcionalidades:
- Criar tarefas
- Listar tarefas
- Atualizar tarefas
- Deletar tarefas (CRUD completo)

📁 Pasta: `/fullstack`

---

🧠 Aprendizados

Durante esse projeto, pratiquei:

- Integração entre frontend e backend
- Criação de APIs com Node.js e Express
- Uso do Prisma para comunicação com banco de dados
- Operações CRUD na prática
- Organização de código em projetos reais

---

💡 Observação

O código está bem comentado (😅), pois utilizei este projeto como forma de estudo e reforço de aprendizado.  
Pode ser útil para quem está começando e quer entender como funciona essa integração na prática.
